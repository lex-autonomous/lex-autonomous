# Ubiquitous Language

Adapted from Matt Pocock's ubiquitous-language skill for Lex Autonomous agent operations.

## Core Principle

**Conversations and deliverables that share a domain model produce better outcomes.**

## Output Format

```
UBIQUITOUS LANGUAGE — [Project/Client Name]
Locked: [Date]

[Term]: [One-sentence definition as used in this project]
...

These terms are fixed for this project. If a term needs to change, flag it explicitly
and update the glossary before continuing.
```

## Enforcement Rules

- Never substitute synonyms for defined terms mid-project
- Add new terms to the glossary before using them
- Flag and correct inconsistent usage immediately
- Glossary updated by explicit agreement — not by drift
